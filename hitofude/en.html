FAQ

FAQ

Is every level solvable?

Yes. Every level was checked by a program to be solvable before it was added. Use a hint if you get stuck.

A level has two gold dots. Which path does each one open?

Each gold dot and the path it opens share the same mark (○ △ □).

I bought Remove Ads but still see ads

Open Settings (the gear at the top right of the home screen) and tap Restore purchase. You need to be signed in with the Apple Account you used to buy it.
